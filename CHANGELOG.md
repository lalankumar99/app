## [1.0.0] - Initial Development

### Added
- Initial Flutter application structure.
- Main application entry point (`lib/main.dart`).
- Modular directories for configuration, data, screens, and services.
- Centralized application configuration.
- Login screen interface.
- Main application interface.
- Material 3 theme configuration.
- Optional Firebase dependency placeholders.
- GitHub Actions workflow for building an Android release APK.
- Initial project documentation.

- Added automated Android APK build workflow.
- Configured Java JDK 17 for the build environment.
- Configured Flutter stable channel.
- Added APK artifact upload after a successful build.

### Documentation
- Added project README.
- Added contribution guidelines.
- Added changelog documentation.
